# Design Reference — NEXUS Creative Lab

Extraído do briefing original do projeto (seção 4) e do PRD aprovado (seção 8).

## Paleta de cores
| Uso | Cor |
| --- | --- |
| Fundo principal (dark) | `#0B0C10` |
| Superfície dos cards | `#1F2833` |
| Texto primário | `#FFFFFF` |
| Texto secundário | `#C5C6C7` |
| Destaque / acento | `#45A29E` |
| Acento vibrante (CTA) | `#66FCF1` |

## Tipografia
- **Títulos (Headings)**: Plus Jakarta Sans ou Syne (Bold / ExtraBold)
- **Corpo de texto (Body)**: Inter ou SF Pro Display (Regular / Medium)

## Requisitos de interface
- **Tema**: Dark mode com contrastes elevados
- **Efeitos**: Blur de fundo (glassmorphism), microinterações em botões ao hover,
  transições suaves de carregamento
- **Responsividade**: mobile, tablet e desktop ultrawide

## Convenção de projeto
Toda decisão de UI neste projeto deve usar a skill `design-taste-frontend`
(github.com/Leonxlnx/taste-skill) como guia.
